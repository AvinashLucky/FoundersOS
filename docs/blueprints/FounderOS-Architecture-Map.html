04

COO Orchestration Loop

Deterministic code wrapping probabilistic agents (T7). Resumable from the event log; bounded by budget & max-revision governors so it always terminates.

Run = create(intent, founder, project)
context = MemoryEngine.retrieve(intent, project) // graph + vector + recency + reuse
plan = COO.decompose(intent, context) // typed task graph + acceptance criteria
depts = COO.selectMinimumSet(plan) // cost-aware activation
budget = CostController.allocate(Run, plan)
while plan.hasReadyTasks() and budget.ok():
  batch = plan.readyTasks() // dependency-respecting
  parallel for task in batch:
    model = ModelRouter.pick(task) // cheapest capable
    artifact = Agent[task.role].run(model, ctx)
    blackboard.write(artifact)
  verdicts = ReviewGateEngine.run(batch) // parallel gates
  plan.applyVerdicts(verdicts) // pass / revise / block → arbitrate
answer = CEO.synthesize(blackboard.accepted())
KnowledgeDivision.persist(Run, blackboard, decisions) // memory · graph · ledger · timeline
return answer + side-channel
05

Model Router — Tiers

Every department reaches models only through the router. It scores each task and picks the lowest-cost candidate that clears the bar — escalating only on failure. New models join a tier via an adapter; no logic changes.

Tier 0

Local

$0

Privacy-sensitive, high-volume, embeddings, offline. The floor & the fallback of last resort.

Tier 1

Fast

$

Classification, extraction, routing decisions, simple drafts.

Tier 2

Balanced

$$

Most specialist work — design, dev, QA, research. The workhorse.

Tier 3

Frontier

$$$

Hard reasoning, architecture, final synthesis, arbitration only.

Registry

Declarative catalog: capabilities, context, cost, quality scores, privacy class, health. Data, not code.

Fallback

Ordered chains; a single vendor outage degrades cost/quality, never availability.

Adapter Contract

capabilities() · cost() · invoke() · stream() · health(). Built for models that don't exist yet.

06

Memory Engine

The moat made mechanical. A curated, decaying, graph-linked asset — not a chunk dump. It makes the OS measurably smarter per founder over time.

L1

Working memory

Run-scoped blackboard. Ephemeral → serialized to the event log.

L2

Project memory

Everything a project accumulates — "a project has its own company".

L3

Founder memory

Lifelong, cross-project knowledge of how this founder builds. Makes it yours.

L4

Knowledge graph

Relational connective tissue across all of the above.

MongoDB

Flexible documents: memory entries, decisions, lessons, timelines, artifact metadata.

Postgres + pgvector

Embeddings + materialized graph edges + RLS isolation. The retrieval & reasoning substrate.

Access Layer

remember() · recall() · link() · record(). One seam over both stores — no agent touches a DB directly.

Evolves over years: consolidation merges related memories into higher-order patterns · decay & salience give memory a metabolism · promotion lifts recurring patterns to founder memory · archival keeps old projects cold but searchable · superseded facts are marked, never silently kept.

Pattern discovery

11

Cross-Cutting Strategy

Scalability

  • Four axes: workspaces · projects · concurrent runs · memory depth.
  • Stateless agents & workers → scale by count; queue absorbs spikes.
  • Consolidation + decay keep the hot retrieval set small as history grows unbounded.

Cost Optimization

  • Don't run it (reuse) → smallest dept set → cheapest model → least context → stop in time.
  • Per-run budgets enforced deterministically; BYO key keeps inference at cost.
  • ≈70% below frontier-everywhere — a property of routing, not a discount.

Security

  • Workspace isolation at the DB (Postgres RLS) — defense in depth.
  • Untrusted external content sandboxed; tools allow-listed per agent.
  • Privacy-tiered routing pins sensitive data to local models.

10-Year Evolution

  • Router + adapter contract insulate against model churn & new modalities.
  • Access-layer seam lets datastores re-balance invisibly.
  • Org-as-data scales solo → studio → enterprise without re-architecture.
