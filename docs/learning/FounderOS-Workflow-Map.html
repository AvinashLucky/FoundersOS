Run the company — where you SEE the agents

This is the heart. Open a project, and in the "run the company" bar, type one idea. Then watch.

/projects/:idThe run panel
› intent input

Type e.g. "Design the onboarding flow and a pricing page".

Run

Streams live (SSE). You watch the company work in real time.

What you watch, in order

The COO plans, the needed departments light up and run in parallel, then the CEO speaks — one answer.

COO
1 · Plan

Activates only the departments the intent needs (token economy). Shows a rationale.

PM
Product

Scope: what to build, for whom.

AR
Architecture

Simplest design that scales.

UX
Design

Flows, states, on-brand.

QA
QA + Security

Risks, edge cases, tests.

CEO
2 · Answer

Synthesizes ONE decisive answer + cost + time.

Each answer is saved to project memory. A budget governor caps spend; every prompt carries an ethics clause. Offline it uses a local model; add ANTHROPIC_API_KEY for real Claude.
