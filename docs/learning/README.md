# Learning — visual guides

Friendly, themed HTML guides that explain FounderOS so you can learn before (and while) you build.
Open the `.html` files in a browser. These are kept current as we complete sprints.

| File | What it explains |
|------|------------------|
| `FounderOS-Learning-Hub.html` | The big picture: who-does-what, project structure, backend & frontend explained simply, the sprint plan, and screen/visual capture. **Start here.** |
| `FounderOS-Phases-1-3-Walkthrough.html` | End-to-end teaching of the built phases (frontend + backend), file by file. |
| `FounderOS-Money-Engine.html` | CEO-POV monetization plan: what to sell, the reskin workflow, addon modules, pricing, and a 30-day sprint. |
| `FounderOS-Workflow-Map.html` | **Click-by-click:** every screen, every button, and where you watch the agents work. |
