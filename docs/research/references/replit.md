# Replit (Agent) — reference for FounderOS

**What it is.** A cloud development environment with an autonomous **Agent** that plans,
builds, runs and deploys apps, plus hosting in the same place. Third-party guides describe
Plan Mode, a "Lite build" for quick edits and a "Full build" for longer autonomous work.
They also report up to 5 builders per workspace and 2 agents in parallel on Core.

**Pricing (third-party, Sept 2026; check replit.com/pricing).**
- Core: about $20–25/month, including about $20–25 of usage credits.
- Pro: about $90–100/month.
- Agent work is billed **by effort per checkpoint**. Replit asks before any paid action
  starts.

**What to learn**
- **Checkpoints:** every unit of agent work is a saved, priced, revertible step. It's the
  same idea as our receipts, but tied to *undo*. FounderOS should make every agent action
  revertible (it also answers "one command must never wipe my code").
- **Ask before spending.** A confirmation before paid work builds trust. Our safety gate
  already refuses *before* spending tokens; add an explicit "this run will cost about $X,
  go?" step.
- **Run + host in one place** removes the "it works on my machine" gap.

**What users say (from pricing guides, not verified by us).** Effort-based costs are hard to
predict, mainly on Pro.

**Where FounderOS is different.** Replit is a place for one builder (or a small team) to
code with an agent. FounderOS is the *company* deciding what to build, showing who
disagreed, and leaving you a project that runs anywhere without us.

**Honest gap.** Replit's run-and-host loop is complete. Ours is a plan (Track A Stage 2 runner).
