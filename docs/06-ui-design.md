# UI Design

> Interactive reference: \`/FounderOS-Design-Showcase.html\`. Tokens in \`packages/ui\`.

**Strata** design language: calm command surface (not a dashboard). Three typographic voices
(company=serif, system=sans, machine=mono), 8pt rhythm, depth-not-shadow, adaptive theme system
(one substrate, per-project accents). Principles, motion language, responsive postures, accessibility,
and the self-critique live in the showcase; this doc tracks design decisions and updates.
