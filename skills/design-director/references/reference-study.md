# Studying a reference site

The goal is to understand **why** a site works and carry those reasons into an original
design — not to reproduce it. Two sites built on the same principles can look nothing alike.

## What to capture (10–15 minutes, a few lines each)

1. **Structure** — which pages exist, how navigation groups them, what the footer holds.
   On the contact page: which fields, which are required, what happens after submit.
2. **Rhythm** — section heights, how much space between sections versus inside them, where
   the page breathes and where it gets dense.
3. **Hierarchy** — how many type sizes are really used, the ratio between headline and body,
   how emphasis is made (size, weight, colour, or space).
4. **Grid** — column count, how strictly elements align, where they deliberately break it.
5. **Colour use** — how many colours carry meaning; where the accent appears and where it never does.
6. **Trust** — what the page uses to earn belief: specifics, numbers with sources, people,
   regulation, process, guarantees.
7. **Interaction** — hover, focus, menu behaviour, transitions, form feedback, loading.
8. **Responsive** — what changes at mobile width beyond stacking.

Write the result as principles: "large type contrast (≈4:1 headline to body); long quiet
sections; one accent reserved for actions; trust from regulatory specifics, not
testimonials." Then pick directions with this skill and apply the principles inside them.

## Boundaries

- Look at public pages only. Don't log in, submit real forms, or use any account but your own.
- Don't copy text, images, icons, logos, code, or a page's exact composition.
- Don't name the reference in the product or its copy, or claim affiliation.
- If you couldn't open the site (blocked, needs JavaScript, no browser), say so and work
  from screenshots or a description — never describe what you didn't see.
